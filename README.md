# تحدّي الأنماط والذاكرة 🔍

لعبة تعليمية عربية بسيطة للأطفال تشرح مفهوم **التعرّف على الأنماط** وتربطه بكيفية تعلّم الذكاء الاصطناعي من الصور والبيانات.

## الفكرة
يشاهد الطفل صورة كاملة لمدة ١٠ ثوانٍ، ثم تختفي وتتحول إلى قطع مبعثرة يعيد تركيبها من الذاكرة — ثم رسالة تعليمية تربط ذلك بالذكاء الاصطناعي.

## التشغيل
ملف واحد مستقل بلا أي مكتبات. افتح `index.html` في المتصفح مباشرة.

## المميزات
- ٥ شاشات: البداية، المشاهدة (عدّاد ١٠ ثوانٍ)، تركيب الصورة، «كيف عرفت؟»، الربط بالذكاء الاصطناعي.
- ٣ مستويات: سهل ٢×٢، متوسط ٣×٣، متقدم ٤×٤.
- سحب وإفلات بالفأرة واللمس، مؤثرات صوتية، دعم كامل للعربية و RTL.

بُنيت بمساعدة Claude Code.
